## Data Architecture
The Data architecture for this project follows the Medallion Architecture **Bronze**, **Silver**, **Gold** Layers:
Bronze: Stores Data from the source system
Silver: Cleanes , standardizes and normalizes the data
Gold: Houses Business Ready Data Modeled into Star Schema required for reporting and analytics.
